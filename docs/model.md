# 빈 차 대기 거점 선정 모델 명세 (v0.1, 8주차)

> 작성: 이소흔 (최적화·백엔드 담당) · 지도교수님 면담 피드백 반영 전 초안을 Facility Location 관점으로 정리한 버전

## 1. 문제 정의
- 배차(호출–차량 매칭)는 경기도 통합 시스템이 담당 → 우리 팀은 **"하차한 빈 차가 어디서 기다릴지"**를 결정
- 차고지(파장동)는 그대로 두고, 병원·재활시설·장애인복지관 **주차장을 대기 거점**으로 활용
- 근거: 출발 상위 격자와 하차 상위 격자가 대부분 겹치고, 핫스팟 하차 후 30분 내 같은 격자 호출 39.2% vs 실제 근처(1km) 재승차 23.5%

## 2. 모델 분류
**시간대별(multi-period) 용량 제약(capacitated) p-median 문제** — Facility Location Problem의 한 종류
| 재료 | 우리 프로젝트 |
|---|---|
| 수요점 i | 500m 격자별 호출 |
| 수요량 d(i,t) | 격자·시간대별 평균 즉시콜 수 (고객 취소 포함) |
| 후보 시설 j | 병원·복지관 주차장 + 차고지 G |
| 비용 τ(j,i,t) | 시간대별 실효속도로 계산한 이동시간 |

## 3. 수식 (기본형)
- 결정변수: z(j,t) ∈ {0,1} 거점 운영 여부, x(i,j,t) ∈ [0,1] 격자 i 호출을 거점 j가 담당하는 비율
- 목적함수: min Σ_t Σ_i Σ_j d(i,t)·τ(j,i,t)·x(i,j,t)  (+ 확장형: λ·빈 차 회차 이동시간)
- 제약식
  1. Σ_j x(i,j,t) = 1 (모든 호출 지역 배정)
  2. x(i,j,t) ≤ z(j,t) (운영 거점만 사용)
  3. Σ_i d(i,t)·x(i,j,t) ≤ U(j,t)·z(j,t) (주차 용량)
  4. Σ_j z(j,t) = P (시간대별 운영 거점 수)

확장형(빈 차 회차 흐름 f, 근무 종료 차량 차고지 복귀 e)은 `면담 사전자료` 참고 — 실데이터 적용 시 단계적으로 추가 예정
